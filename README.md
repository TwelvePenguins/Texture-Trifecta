# Texture Trifecta

An iOS app that turns textures from the world around you into personalised artwork.

Texture Trifecta was created for the **Apple Swift Student Challenge 2023**. The project began with a simple goal: encourage my younger brother to look up from his screen and pay more attention to the details (especially textures) around him — the scratches on a surface, veins on a leaf, cracks in the pavement, or patterns in everyday objects.

Instead of simply photographing these details, Texture Trifecta lets users collect them and turn them into something unique – a mosaic!

## How It Works

Texture Trifecta follows three steps:

### Capture

Explore your surroundings and photograph interesting textures, colours and patterns using the in-app camera.

### Create

Choose from illustrated animals and apply collected textures to different sections of the artwork.

Textures can be mixed and matched across individual parts, with support for zooming in to work on smaller details.

### Compile

Bring the completed animals together into a scene and see the artwork built from the textures you discovered.

The initial collection, **Antics in Antarctica**, features a penguin and an orca.

## Features

- In-app camera for capturing textures
- Local texture collection
- Interactive section-based artwork editing
- Custom masking to fit photographs within illustrated shapes
- Pinch-to-zoom artwork interaction
- Persistent saved designs
- Animated completed scenes

## Built With

- **Swift**
- **SwiftUI**
- **UIKit**
- Apple camera and photo APIs
- Local file storage

## Running the Project

The project was originally developed as a Swift Playground App for the 2023 Swift Student Challenge.

1. Clone the repository:

```bash
git clone https://github.com/TwelvePenguins/Texture-Trifecta.git
```

2. Open the project in **Xcode** or **Swift Playgrounds** on a compatible Apple platform.

3. Run the application on an iOS device or simulator.

Camera functionality requires a device with camera access.

## Background

Texture Trifecta was deliberately designed as a small, personal project rather than a general-purpose art application.

The artwork and interactions were shaped around my brother's interests — including, naturally, penguins — while the core idea was to make observing the physical world part of the creative process.
